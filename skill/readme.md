# PYNQ 实测产物与黄金参考校验技能

2026-11-02 更新：可直接加载的技能入口为 [SKILL.md](skill.md)。[owner_lifecycle.md](owner_lifecycle.md) 补充从实际 native-frame 死锁中提炼的 DMA 生命周期判断流程，不包含任何板卡寄存器常数。当前回归入口为 `python scripts/check_completion_skill_20261102.py --output <新目录>`，覆盖正常/错误哈希/错误字节/空范围/越界/目录逃逸/空清单/合法局部比较，并对当前安装版真实文件核对。旧验证原件保留，不覆盖 `reports/submission/skill_check`。

适用于从任意 PYNQ／FPGA 项目导出的 bit、HWH、程序、输入、板测日志和二进制结果。工具只用 Python 标准库，不依赖本项目寄存器、板卡地址、SSH 账号或 PYNQ 安装。也可用于其他嵌入式项目的离线产物核对。

## 目的与来源

本工程曾遇到旧通过记录、不同服务版本及残留硬件状态影响判断。经验是：先绑定版本，再比较输出，最后解释测量范围。脚本处理前两项的字节证据；硬件接口和结果语义由项目自己的检查器负责。

`verify_artifacts.py` 不连接板子、不加载 bit、不写寄存器，也不删除或修改待测文件。输出 JSON，成功退出 0、发现差异退出 1。

## 使用

1. 用项目自己的程序采集实际输出，用独立模型或已确认的输入／输出规范生成黄金参考，固定双方格式。
2. 创建清单，`files` 为相对产物根目录的文件名与 SHA256；`comparisons` 描述二进制比较范围。例如：

```json
{
  "files": {"top.bit": "填写实际64位小写sha256"},
  "comparisons": [
    {"actual": "board.bin", "reference": "golden.bin"},
    {"actual": "framed.bin", "actual_offset": 16,
     "reference": "payload.bin", "length": 4096}
  ]
}
```

不需要文件哈希或二进制比较时可分别省略对应字段，但不接受没有任何检查的空清单。全部路径必须落在 `--root` 内。全文件比较要求等长；部分比较必须明确正长度，拒绝范围越界，以免空切片被误判通过。

```powershell
python skill/verify_artifacts.py --root /path/to/artifacts --manifest /path/to/check.json
```

上述命令使用用户提供的产物和清单，不重新运行板测。迁移到其他题目时只需更换产物根目录、文件哈希与比较清单；脚本本身不包含 640×480 或 RV32I 假设。

## 已验证的效果

- 使用本项目统一验收清单验证版本身份，涵盖实现报告、bit、应用、板测输出和重启记录；实际文件数见每次校验输出。
- `python scripts/check_submission_skill.py` 执行正常案例、哈希错误、结果字节错误、空比较范围、越界范围和目录逃逸检查；记录见 `reports/submission/skill_check/result.json`。
- 板上图形正确性另由独立场景参考检查器完成，40 张画面结果见 `reports/system640_menu/board/`。不把通用脚本的哈希通过等同于重新证明这些画面正确。

## 失效条件和边界

- 黄金参考必须独立可靠。直接把板上实际结果复制成“参考”只能检查文件复制，不能证明功能。
- 动态时间戳、计数器、随机种子、浮点误差、端序或像素格式不同会导致字节差异；应事先固定输入并定义需比较区域，不能为了通过任意跳过错误区域。
- 校验同一份陈旧清单与陈旧文件可以通过；清单必须来自当前实际运行且包含运行身份。脚本不证明远端进程仍在运行，也不证明缓存已 flush。
- 输出大小超过主机内存时应改用流式工具；本脚本面向常见 bit、帧缓冲和日志大小。
- 本工具没有跨板卡实际运行测试；已验证的是其不含板卡依赖的离线检查路径。不同板卡仍需自己的采集和硬件健康检查。

历史回归命令与原工作区路径仅说明技能形成过程；公开使用方法以上面的清单示例为准。DMA 生命周期见本目录 owner_lifecycle.md，不直接套用其他工程寄存器地址。
