# 留待现场补充的人工检查

当前持久版为 `native800_final_visual_a`。用户明确允许自动工作先收尾，实拍和现场体验留待自己完成；以下项目不是本轮自动任务的阻塞项，也不冒称已经通过。正式版、此前稳定版和原素材H均保留，视频暂不制作。

1. **体验菜单、两款应用和声音。** 触屏双击卡片进入，鼠标左键进入、右键返回，手柄优先；虚拟方向/OK条已移除。两款展示均用LT/RT选三挡，长按只切一挡，两端不循环。鸡蛋同波内部10秒循环，不自动换波；普通游戏流程保持。确认默认音量5、仅星际战斗音乐跳过前5秒，右上角无遮挡。CPU计量时返回需要等待当前测量完成。
2. **正常退出后做一次物理关机/再上电。** 先确认当前运行时正常退休与DMA排空；再按实验室规范关机。确认上电自动进入最新版菜单且手柄有效。此前只验证了服务安装/启动，未声称本版本物理断电启动通过。失败时保留现象与日志，勿反复强杀、叠加加载。
3. **补3张真实照片。** 整体正面、约45°整体、USB与供电接线；触屏/手柄操作特写可选。性能页和运行界面已由板端直接截图，不需逐页实拍；截图与AI预览不能标成实物照片。详见实拍清单。
4. **按需检查冷启动或长休眠后的输入。** 保持已经验证的旧hub、触屏、G102、有线手柄及额外供电。普通和约1秒重插已有用户确认，不要求重复无结论的矩阵；冷启动和长休眠尚未验收。如有异常，保留现象并先读活态，勿自行反复重置USB或强杀显示owner。
5. **确认参赛信息与匿名要求。** 核对题目名称、组别、队员信息、提交平台及最终模板要求；本轮未猜测姓名/学校。检查两份报告和中英文海报，补必要信息和实拍后重新导出，确认A4彩印效果。官方通知若更新，以实际通知为准。
