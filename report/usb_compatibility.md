# USB输入的已知范围与限制

## 2026-11-03 当前结论

当前为 `native800_final_visual_a`，保留手柄→触屏→鼠标优先级。主菜单触屏双击卡片、鼠标左键进入；右键/触屏SELECT返回。针对下述精确旧hub、G102、VADER4/P008组合，`rvgame-usb-priority.service`停用鼠标附加键盘接口；手柄重连时临时释放鼠标主接口，等有效手柄输入后恢复。用户已确认普通及约1秒快速重插后三输入自动恢复；新菜单自动回放与两款应用板测另行记录。冷启动、长期休眠与其他设备组合仍不在通过范围。

服务源和说明在 `runtime/usb_priority/`，P008持续轮询在 `runtime/usb_touch/`。它们不写PL/MMIO、不重置USB主机；USB主机或接口试验前先正常停兼容服务并核恢复记录。此次未修改内核，也不把已验证的兼容办法等同于EHCI根因修复。

## 历史失败与排查边界（保留原记录，以下不是当前状态）

本版为`native800_input_robustness_a`：点按卡片选择，OK/A确认进入；应用中鼠标右键或触屏底部提示区触发原SELECT安全返回。游戏操作保留手柄。主菜单和进入/返回有事件回放、实板像素/CRC证据；实体三输入曾短时正常，后来手柄唤醒/重连使三者失效，尚未通过共存验收。软件不要求PC替板卡实时绘图。

当前接法：板卡→旧05e3:0608 USB2集线器；飞智045e:028e手柄、P008 1a86:e5e3触屏、G102 046d:c092鼠标接集线器。集线器额外安卓式供电口由电脑USB供电，HDMI接板卡。供电额定值未核定。鼠标的加入由用户确认，未因此认定三设备共存通过。

P008曾在不读取输入而人工触摸的120秒内发生9次重枚举；持续读取窗口无重枚举。`rvgame-p008-poll.service`只打开已核描述符的evdev并持续排空，不写MMIO、不重置USB。轻量候选、正式服务后的两分钟及一次软重启后的两分钟均有证据，用户当时确认手柄操作/静置和屏幕正常。软重启早期、服务打开设备之前仍有一次重枚举；物理断电与长期稳定不在通过范围。

三设备组合曾出现G102的evdev打开返回`errno 16 / Device or resource busy`。随后实际系统调用跟踪捕获手柄`USBDEVFS_CLAIMINTERFACE`成功、`USBDEVFS_SUBMITURB`返回`ENOSPC`。这是周期传输资源拒绝的直接证据；Linux6.6上游`usbhid_open`也有将`-ENOSPC`映射成`-EBUSY`的路径，见[上游源码](https://github.com/torvalds/linux/blob/v6.6/drivers/hid/usbhid/hid-core.c)。旧hub为480Mb/s单TT，三个设备均为全速，相关中断端点的原描述符间隔为1ms。当前内核未启用`CONFIG_USB_EHCI_TT_NEWSCHED`；[上游Kconfig](https://github.com/torvalds/linux/blob/v6.6/drivers/usb/host/Kconfig)提供了后续调度排查依据，尚未形成经过验证的内核修复。

此外，手柄唤醒/重枚举曾触发配置描述符读取`-32/-110`、`clear tt`超时及整个USB链停止进展。屏幕可一直稳定显示，不能据此排除数据故障。不能把这条故障链直接等同于ENOSPC，也不能归因于2.4G：用户已换回有线后仍报告重连失效。

4ms/8ms mousepoll尝试未解除EBUSY，已恢复原值。G102伴随键盘接口短暂解绑曾使主鼠标打开；产品内保留仅匹配双描述符和旧单TT hub、每次枚举最多一次的受限恢复，但安装启动未触发该分支，不能宣称自动恢复已完成实际验收。更深入的临时内核模块把已知三个HID端点描述符间隔改为8ms，并以SET_INTERFACE刷新端点；另对飞智尝试初始化等待。A/C有采样，B/D在触屏重枚举失败时提前退出，均未达到功能通过条件。模块已卸载、描述符恢复、usbcore.quirks恢复空值，原应用服务恢复。恢复成功与USB功能通过分开记录。

实验模块只在隔离目录构建、加载后回退，没有修改启动内核、模块自动加载或系统默认编译器。它不随独立运行目录作为依赖。当前内核为`6.6.10-xilinx-v2024.1-g9299000c9490`；已匹配本机头文件/Module.symvers，但未取得对应提交的完整内核源，上游6.6只是参考。用户暂离后所有硬件试验已结束；返回后仍用旧集线器，先核对活态再安排必要操作。

运行目录附`usb_touch`服务源、安装器与回退说明。新镜像需满足现有PYNQ、内核/HID debugfs和设备描述符条件；它不是全新SD镜像或任意USB触屏兼容包。不得把“原始输入曾通过”“主菜单回放通过”和“三设备实物验收通过”合并为一个结论。
