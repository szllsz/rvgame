| --- | --- | --- |

两份 Markdown 为技术整理稿，按问题与验证关系修缮表述；同名 JSON 保存选中的原始提示词和模型回答片段，保留角色、时间、源行号及省略标记。整理稿中的 E1—E4、R1—R7 与 JSON 编号对应。

`selection_receipt.json` 登记文件哈希和节选核对结果。技能方法的适用范围、执行命令及验证效果见 [skill/README.md](../../skill/README.md)。
