# 原始截图与底部诊断区

本目录 PNG 是实际板端 RGB332 帧缓冲回读，不是实物照片。

自动采集使用 `--test-input --capture-metadata`，图形程序将校验数据写入底部像素。`07_tile`、`08_ddr_bitmap`、`09_alpha` 末尾 64 字节的程序标识分别为 `0x47584631`、`0x424d5031`、`0x414c5031`；帧号反码及对象数核对一致，前一段还保存帧率历史。RGB332 转换会把这些数字显示成彩色短线。CPU 图中底部 8 行为自动检查保留的诊断区。

这是测试模式的数据，不是中文字体乱码，也不表明已出现显存花屏。正常入口未传入 `--capture-metadata`，其启用还受 `--test-input` 条件约束。

原始 PNG、截图册及相应回读哈希保持不变。新 `competition_report.docx` 只在排版中用图像裁切属性隐藏 CPU 底部 8 行和 TILE／Alpha 底部 2 行；嵌入 PNG 的像素未重画或替换。PDF 为对应 Word 导出。裁切说明也写在报告图形成果段，原始证据仍可完整复核。
