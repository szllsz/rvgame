# 许可与素材来源

本目录保留现有上游许可文本和来源哈希；详细使用边界见report/contribution_and_sources.md。硬件包内Digilent IP源文件还保留其原始版权/许可头，RISC-V ISA及AMD工具/IP不计自主原创。

本项目原创代码使用根目录 MIT 许可。Kenney 视觉素材为 CC0；字体按各自 OFL 文本处理；APU 含 fpganes GPL 来源，Digilent 视频 IP 保留源文件中的 BSD 条款，CoreMark 保留 Apache 许可。第三方部分不被根目录 MIT 重新授权。

项目作者已明确确认现有音乐作为作品配乐随运行包公开；本仓库保留曲目和处理记录，不把配乐标成原创音乐或单独音乐产品。当前星际视觉使用 Kenney CC0、原有字体及本次 AI 生成怪兽；未使用的旧菜单图标和旧展示图数组已从公开源码剔除。鸡蛋兄弟的既有来源和游戏规则如实登记，不因项目更名而改称全部原创。详见 [贡献与来源](../report/contribution_and_sources.md)。
